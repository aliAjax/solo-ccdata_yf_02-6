# 离线物料需求计划台（MRP Workbench）

纯前端、可离线运行的多层物料需求计划工具：直接用浏览器打开 `index.html` 即可，无需服务器、无外部依赖。数据保存在浏览器 localStorage，刷新后自动恢复。

## 功能

- **数据维护**：物料（含名称与提前期）、按可用日期登记的库存、成品订单、多层 BOM（父子单位用量 + 损耗率）。
- **逐层点算**（低层码 low-level code 自上而下）：
  - 毛需求：成品订单 + 父件计划单按 `单位用量 / (1 − 损耗率)` 展开；
  - 净需求 = 毛需求 − **同一日期**的库存占用，向上取整生成计划单；
  - **库存只能被同一时段（同一天）的实际需求占用**，不同日期互不挪用；同日多笔需求按产生顺序竞用；
  - 倒排排期：到货日期 = 需求日期，投产日期 = 到货日期 − 提前期；投产日早于今天即列入缺料/缺口。
- **错误阻断**：缺料引用、非法数量/日期/提前期、损耗率越界、重复父子关系、BOM 循环依赖（含自循环）都会列出具体物料（含环路径），并阻止生成计划；结果区不残留上一轮结果。
- **完整重算**：任意订单/库存/BOM 调整后，所有受影响层级与日期基于原始数据重新计算（结果对象每次全新）。
- 支持 JSON 导入/导出、一键载入多层共用件示例。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 界面（订单/物料/库存/BOM 四个维护页 + 逐层结果与倒排计划） |
| `app.js` | 交互层：编辑、localStorage 存档、结果渲染、错误行高亮 |
| `mrp.js` | 纯函数 MRP 引擎（无 DOM 依赖，浏览器/Node 共用，含 UMD 导出） |
| `test/mrp.test.js` | 引擎场景测试（24 项） |
| `test/ui.test.js` | jsdom 界面端到端测试（11 项） |

## 运行测试

```bash
node test/mrp.test.js
node test/ui.test.js     # 需安装 jsdom：npm i jsdom（仅测试依赖）
```

## 已核对场景

多层共用件汇聚（同一子件被多层多父件引用）、库存同时段竞用与跨时段隔离、循环依赖阻断、缺料/非法数量/重复父子阻断、提前期倒排与缺口、改单/改库存后全层级重算无旧结果残留、localStorage 刷新恢复。
